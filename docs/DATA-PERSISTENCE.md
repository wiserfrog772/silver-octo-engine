# Сохранность данных Crimson

## Где что хранится
| Данные | Место | Переживает переустановку? |
|---|---|---|
| Плейлисты, порядок, настройки | `localStorage` WebView (запись с контрольной суммой + предыдущая копия `.bak`) | Нет (данные приложения) |
| Резервная копия (основная + 5 архивных) | `files/backup/` приложения | Да, если включён Google Backup (правила `crimson_backup_rules.xml`) |
| Плейлисты с музыкой | `Crimson Playlists/<название>/` внутри папки, выбранной пользователем: треки + `crimson-playlist.json` (порядок) | **Да**, лежит вне данных приложения |
| Ручной экспорт | файл, выбранный пользователем (Настройки → Экспорт плейлистов) | Да |
| Библиотека треков | IndexedDB WebView (схема v2, индексы) | Нет; пересоздаётся сканированием папки |

## Как работает восстановление
Плейлист хранит не только `trackIds`, но и ссылки `refs` (название, исполнитель, источник, длительность).
После переустановки id треков меняются, поэтому плейлисты сопоставляются с заново отсканированной
библиотекой: `id → источник → videoId → исполнитель+название`. Пока трек не найден, ссылка ждёт и
подтягивается после сканирования. Копия выбирается автоматически: самая свежая исправная из всех источников.

## Удаление приложения
- `android:hasFragileUserData="true"` — Android 10+ спросит, сохранить ли данные при удалении.
- Если данные сохранены и APK подписан тем же ключом, всё вернётся как было.
- Debug-сборки из CI подписываются случайным ключом: поверх друг друга и «с сохранением данных» они не ставятся.
  Для надёжности используй постоянный release-keystore.
- Если приложение удалено полностью: выбери папку с музыкой — Crimson найдёт `Crimson Backup` и предложит плейлисты.
- «Удалить все данные…» в настройках стирает данные приложения и все копии (с двойным подтверждением).

## Ограничения
- Файлы музыки в выбранной папке никогда не удаляются.
- Auto Backup зависит от настроек Google на устройстве и не гарантирован.

## Плейлисты-папки (вместо копий во внешней папке)
- Создание, переименование, изменение состава или порядка плейлиста записывается в его папку (через 2,5 сек. после изменения).
- Треки копируются в папку плейлиста (место занимается дважды). Crimson удаляет только файлы, которые скопировал сам (список `managed` в манифесте).
- Папка «Crimson Playlists» не сканируется как медиатека, поэтому дубликатов в библиотеке нет.
- После переустановки: выбери ту же папку → скан → плейлисты находятся и восстанавливаются в прежнем порядке; треки, которых нет в библиотеке, добавляются из самой папки плейлиста.
- Треки без локального файла (импорт через выбор файла) в папку не копируются.
