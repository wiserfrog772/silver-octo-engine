# Определение исполнителя и названия

Единственная точка: `www/modules/track-identity.mjs`. Её используют скачивание (теги и имя файла), воспроизведение
потока, разбор имён файлов библиотеки, сопоставление YouTube ↔ библиотека и исправление старых записей.

Приоритет: `artists`/`artist` + `track` → `album_artist`/`creator` → «Исполнитель - Название» из названия видео →
канал только вида «Artist - Topic» / VEVO → иначе исполнитель неизвестен (название сохраняется целиком).

Правила: гости `feat./ft./featuring` переходят к исполнителю («Artist feat. Guest»), информация не теряется;
расширение снимается только у настоящих аудио-расширений; номер позиции («123. Название - Артист») убирается лишь
когда после него остаётся «Исполнитель - Название»; служебными считаются только сегменты, целиком состоящие из
служебных слов (Official Video, Lyrics, HD, 1080p…).
