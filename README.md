# Localify Crimson — Android

Мобильный музыкальный плеер Localify Crimson с тёмно-красной темой и встроенным поиском музыки на YouTube.

## Возможности

- Импорт и локальное хранение аудиофайлов.
- Воспроизведение, поиск, очередь, перемотка, случайный порядок и повтор.
- Создание плейлистов, добавление и удаление треков в подборках с сохранением на устройстве.
- Длительность аудио определяется по метаданным в фоне после импорта, чтобы добавление файлов не блокировало интерфейс.
- Добавление следующих треков текущей медиатеки или плейлиста в очередь, начиная после текущей композиции.
- Полноэкранный плеер открывается нажатием на мини-плеер; свайп по обложке переключает треки.
- Поиск YouTube через встроенный youtubedl-android.
- Потоковое воспроизведение найденных треков.
- Скачивание лучшей доступной аудиодорожки с резервным преобразованием в MP3 через FFmpeg внутри APK.
- Нативное фоновое воспроизведение через Android ExoPlayer и MediaSession: пауза, следующий/предыдущий трек и перемотка работают независимо от активности WebView.
- Android foreground service сохраняет очередь и системное уведомление во время воспроизведения; ExoPlayer управляет CPU wake lock только на время проигрывания, а таймер прогресса интерфейса останавливается при сворачивании приложения.
- Импортированное аудио по необходимости переносится в приватные файлы приложения для доступа нативного плеера без зависимости от `blob:` URL WebView.
- Добавление загруженных аудиофайлов в медиатеку Localify.
- Импорт cookies.txt в формате Netscape как запасной вариант, если YouTube требует вход.
- Обложки треков, кэширование обложек и защита от повторного импорта одних и тех же файлов.

Радио не включено.

## Встроенный загрузчик Android

В APK используются:

- io.github.junkfood02.youtubedl-android:library:0.18.1 для поиска, получения аудиопотока и загрузки;
- io.github.junkfood02.youtubedl-android:ffmpeg:0.18.1 для преобразования аудио в MP3.

Загрузчик запускается по требованию. При первом поиске, прослушивании или скачивании библиотека извлекает встроенные runtime-компоненты во внутренний каталог приложения. Проверка статуса и открытие экрана не запускают извлечение.

Загрузчик автоматически выбирает **лучшую доступную аудиодорожку** с помощью `bestaudio`. Обычно это Opus или M4A, но кодек зависит от того, что yt-dlp получает для конкретного ролика. Если исходную дорожку не удаётся скачать, резервная попытка извлекает звук и сохраняет MP3 с помощью FFmpeg. Видео не загружается; формат выбирается автоматически и отдельной настройки для него нет.

Для извлечения аудио включён QuickJS, а EJS-скрипты решения JavaScript-проверок yt-dlp при необходимости получает с GitHub. Загрузчик больше не закреплён за одним клиентом YouTube `android`: yt-dlp может выбирать доступные клиенты, чтобы не терять аудиоформаты, которые конкретный клиент не отдаёт. Если YouTube требует авторизацию/PO Token или блокирует запросы, загрузка всё ещё может не пройти; предупреждения yt-dlp не скрываются, чтобы такие сбои было проще диагностировать.

На Android 10 и новее готовые файлы сохраняются в общую папку **Music/Localify Downloads** через MediaStore и добавляются в библиотеку Localify. Если в настройках выбрана собственная папка загрузок, приложение использует её. На Android ниже 10 используется доступный приложению каталог Music, поскольку MediaStore с RELATIVE_PATH там недоступен.

Поиск, потоковое воспроизведение и загрузка используют импортированный cookies.txt, если он есть. Ошибка HTTP 403 не обязательно означает, что нужен вход: YouTube также может отклонять запросы без причины, связанной с авторизацией.

### Архитектура APK

Сборка включает только ABI **arm64-v8a**, чтобы не упаковывать дополнительные копии больших нативных runtime-компонентов. Устройства только с 32-битным ARM (armeabi-v7a) или x86 не поддерживаются.

## Скачать APK

Последняя успешная сборка публикуется в [GitHub Releases](https://github.com/goofyplanets/animated-sniffle/releases). Рабочий процесс также загружает APK как артефакт в [GitHub Actions](https://github.com/goofyplanets/animated-sniffle/actions).

## Сборка локально

Требуются Node.js 22+, Java 21 и Android SDK.

    npm install
    npx cap add android
    npm run prepare:android
    npx cap sync android
    cd android
    ./gradlew assembleDebug

Файл: android/app/build/outputs/apk/debug/app-debug.apk.
